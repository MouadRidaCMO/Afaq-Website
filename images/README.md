# Images

Drop image files here, then tell me and I will wire them into the site.

Upload via GitHub: open the repo → **Add file → Upload files** → drag into the
right folder below → **Commit changes**.

## Where things go

| Folder | What goes in it | Filename to use |
|---|---|---|
| `hero/` | The main photo for the top of the homepage, beside the headline | `hero.jpg` |
| `founders/` | Headshots, square or portrait, face roughly centred | `mouad.jpg`, `aya.jpg` |
| `campus/` | Budapest, campuses, student life, used later in the universities section | anything, e.g. `elte.jpg` |

## What works best

- **Format:** `.jpg` for photos, `.png` only if it needs a transparent background.
- **Size:** around 1600px on the long edge is plenty. Bigger just slows the site down.
- **Hero photo:** landscape or square works best. Something with space around the
  subject so it does not feel cramped next to the text.
- **Headshots:** square crops. They are displayed as circles, so keep the face
  away from the very edge.

Do not worry about compressing or resizing. Upload the full quality file and I
will resize and optimise it, the way I did with the logo.

## Rights

Only upload photos you took, paid for, or are licensed to use. Photos pulled
from a university website or a Google Images search are usually someone else's
copyright, and a commercial site is exactly where that gets noticed.
